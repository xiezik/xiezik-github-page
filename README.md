## 代表项目

### HumanoidArena

人形机器人需要在移动、接触、平衡与操作之间协调全身，而不只是分别完成走路和手臂操作。HumanoidArena 聚焦下肢不可替代的全身交互，为全身控制与学习提供可比较、可诊断的 benchmark。

[项目主页、论文与代码](https://humanoidarena.github.io/)

### HumanoidArena-Real

将仿真中的全身控制研究衔接到真实机器人，连接全身与灵巧手遥操作采集、数据记录和真机策略推理。它关注真机执行链路，而不将选取的演示片段作为通用任务成功率的证明。

### Egocentric WAM 预训练与后训练

第一人称世界动作模型需要学习视觉与动作之间的联系，并面向具身任务开展后训练。我的相关实习职责是参与 egocentric WAM 的预训练与后训练工作。

### 红鸟项目 · 场景与数据闭环

真实场景中的具身研究需要连接场景重建、数据生成、遥操作与训练，而不止是单点采集。这个项目围绕这些环节之间的闭环开展系统研究，与 HumanoidArena-Real 的真机执行链路区分展示。
